ForgeLang Reference

A compact, safe language for writing finite graph-theory conjectures.

Program structureLogicArithmeticQuantifiersFunctionsCurrent limits

1. Program structure

Every program declares a name and a formula. At present, the outermost quantifier must range universally over simple graphs.

conjecture "Minimum Degree Hamiltonicity":
    V(G in SimpleGraphs:
        (connected(G) & min_degree(G) >= 2) => hamiltonian(G)
    )

Use # to start a comment. Whitespace and line breaks separate tokens but do not change operator precedence.

4. Quantifiers

V means “for every”; E means “there exists”. Nested quantifiers range over vertices of the current graph.

V(v in Vertices(G): degree(G, v) >= 1)
E(v in Vertices(G): degree(G, v) == 0)

The outer form V(G in SimpleGraphs: ...) is required. Top-level existential graph claims are not supported yet.

6. Important limits and semantics

  • ForgeLang is not Python; arbitrary Python expressions and attribute access are not allowed.
  • Arithmetic operands must evaluate to integers.
  • / only succeeds when the quotient is an integer. Use // for floor division and % for remainder.
  • Division or modulo by zero raises a ForgeLang semantic error.
  • Exponentiation accepts non-negative integer exponents up to 1000.
  • The checker searches only the finite graph range configured in the app. Finding no counterexample in that range is not a proof of the conjecture.
